# 🚌 SmartPass: Digital Bus Pass System

A modern web-based portal for students to apply for bus passes with automated admin verification.
## ✨ Key Features
- **Modern UI**: Clean split-layout with Glassmorphism.
- **Photo ID**: Live passport photo preview and display on digital pass.
- **Admin Panel**: Built-in document viewer and approval system.
- **Digital Pass**: Scannable QR-coded student identity cards.

## 🛠️ Tech Stack
- **Backend**: PHP 8.x, MySQL.
- **Frontend**: Bootstrap 5, JavaScript.

## ⚙️ Setup
1. Import `db/database.sql` into phpMyAdmin.
2. Configure `config.php`.
3. Run on XAMPP at `localhost/online_bus_pass`.
